# EcomLens Pro Max

**Enterprise Desktop Solution for Product Scanning and Recording**

EcomLens Pro Max is the online-activated edition of EcomLens — a desktop application for businesses that need a reliable way to **scan products, record videos, and manage visual data**. With online license activation, a secure login system, MP4 video storage, and a structured dashboard, EcomLens Pro Max streamlines how enterprises capture, access, and share product information, under the Jinzy brand.

---

## ✨ Key Features

- **Online License Activation** – One-time purchase via Razorpay, activated with a license key; works offline day-to-day after activation
- **Login & Signup System** – Secure, password-hashed access for authorized staff on an activated installation
- **Dashboard** – Centralized view for managing products and recordings, with a live "Today" recording count
- **Barcode Scanning** – Quickly identify and log products using barcode input, with automatic camera + scanner connection detection
- **Video Recording** – Capture high-quality product videos directly within the application, with automatic save on session end
- **Standard MP4 Storage** – Videos are saved in MP4 format for universal playback and sharing
- **Recordings Library** – Search recordings by barcode (contains/starts-with/ends-with) and date range, grouped by day for fast browsing
- **Settings** – Configurable storage location, camera selection, and account info
- **Tutorials** – Built-in walkthrough videos (English/Hindi)

*Prefer no install? The same scan-triggered recording is also available as a pay-per-scan web app — see [`../api/README.md`](../api/README.md#-web-app--key-features-app).*

## 🚀 Getting Started

### Installation
1. Purchase a license and download the installer from jinzy.com.
2. Install the application (Windows supported; see [DEVELOPER.md](DEVELOPER.md) for cross-platform notes).
3. Enter your license key to activate (requires internet access once).
4. Create an account and log in to begin scanning and recording products.

### System Requirements
- Windows 10 (latest version recommended)
- Minimum 4 GB RAM and 500 MB storage
- Webcam for recording
- Barcode scanner or camera with scanning capability
- Internet connection for initial activation (not required day-to-day afterward)
